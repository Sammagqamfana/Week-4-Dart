# Week 4 Dart Assignment

This project contains small Dart programs that demonstrate key programming concepts like:

- String manipulation  
- Collections (Lists, Sets, and Maps)  
- File handling  
- Date and time operations  

## 🧩 Files Included
- **string_manipulation.dart** – shows how to work with strings  
- **collections_demo.dart** – demonstrates lists, sets, and maps  
- **file_handling.dart** – reads and writes data to files  
- **date_time_demo.dart** – works with the DateTime class  
- **final_assignment.dart** – combines all utilities into one application

## 🚀 How to Run
Make sure you have Dart installed.  
Then open your terminal and run any file, for example:

```bash
dart run final_assignment.dart
